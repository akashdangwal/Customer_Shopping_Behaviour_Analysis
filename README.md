# Customer_Shopping_Behaviour_Analysis
A data analysis project focused on understanding customer shopping behaviour using python, SQL, and Power BI.  The project includes data cleaning, exploration, visualization, and dashboard creation to identify purchasing patterns, customer preferences, and business insights that can support better decision-making.

## Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI. The objective is to clean and explore the dataset, identify key business insights, perform database analysis using SQL queries, and create an interactive dashboard for data-driven decision-making.

## Dataset

The dataset contains customer shopping transaction data, including information such as:

* Customer Details
* Product Categories
* Purchase Amount
* Quantity Purchased
* Payment Methods
* Sales and Profit Metrics
* Transaction Dates

The dataset was used to understand customer purchasing patterns and business performance.

## How to Run

### Python Analysis

1. Clone the repository.
2. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy
   ```
3. Run the Python scripts for data cleaning and EDA.

## SQL Analysis

1. Import the dataset into PostgreSQL, MySQL, or SQL Server.
2. Execute the provided SQL queries.
3. Review generated insights and reports.

## Power BI Dashboard

1. Open the `.pbix` file in Power BI Desktop.
2. Refresh the data source if required.
3. Explore dashboard insights using filters and visualizations.
